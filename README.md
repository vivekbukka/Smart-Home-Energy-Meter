# Smart-Home-Energy-Meter
Smart Home Energy Meter is an IoT-based project using ESP32/ESP8266 and energy sensors to monitor electricity usage in real time. It displays voltage, current, power, and energy consumption on a mobile app or cloud platform. Users can track usage, reduce wastage, and improve efficiency.  smart monitoring, and home automation concepts.
